### 🎙️ AudioInvest

Projeto desenvolvido durante o **DIO Santander Bootcamp 2026 — AI Java Backend**.

A aplicação utiliza comandos de voz relacionados a investimentos, integrando backend Java com **Spring AI**, **Tool Calling**, modelos de áudio e persistência em PostgreSQL.

**Principais tecnologias:**

`Java` `Spring Boot` `Spring AI` `Spring Data JPA` `PostgreSQL` `Docker` `Gradle` `API REST`

🔗 **[Ver projeto no GitHub →](https://github.com/PauloDev-Full/AudioInvest)**

### 🤖 ibm_bob_geo_explorer

Servidor **MCP (Model Context Protocol)** desenvolvido para integrar o assistente IBM Bob à plataforma DIO.

O projeto possui uma suíte de **86 testes automatizados**, com **99% de cobertura**, além de pipeline de **CI/CD utilizando GitHub Actions**.

**Principais tecnologias:**

`Python` `TypeScript` `Node.js` `MCP` `Express` `pytest` `GitHub Actions`

🔗 **[Ver projeto no GitHub →](https://github.com/PauloDev-Full/ibm_bob_geo_explorer)**

### 💰 Calculadora CDI

Aplicação desenvolvida em **Java 21** que consulta a taxa diária do CDI através da API de Dados Abertos do BACEN e realiza projeções de rendimento.

O projeto utiliza os padrões de projeto:

* **Singleton**
* **Strategy**
* **Facade**

**Principais tecnologias:**

`Java 21` `REST API` `BACEN` `Jackson` `Gradle` `Design Patterns`

🔗 **[Ver projeto no GitHub →](https://github.com/PauloDev-Full/calculadora-cdi-design-partterns)**
